# Presentación del Sistema de Gestión Escolar

## Qué se puede mostrar

1. **Inicio de sesión** con diseño femenino y moderno.
2. **Panel principal** con acceso rápido a Estudiantes, Cursos, Notas y Reportes.
3. **Estudiantes**: registra nuevos alumnos, revisa la lista y elimina registros.
4. **Cursos**: muestra materias y horarios.
5. **Notas**: visualiza calificaciones existentes.
6. **Reportes**: muestra un gráfico de notas y métricas clave.

## Mensaje para el cliente

- La aplicación es un prototipo funcional con frontend en React + Vite.
- El backend usa Express y una API REST para gestionar estudiantes.
- El estilo es femenino, claro y profesional, ideal para ventas.
- El proyecto está listo para producción: `npm run build` funciona correctamente.

## Cómo ejecutar rápido

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Ejecutar frontend:
   ```bash
   npm run dev
   ```
3. Ejecutar backend en otra terminal:
   ```bash
   cd server
   npm install
   npm start
   ```
4. Abrir en el navegador:
   ```
   http://localhost:5173
   ```

## Recomendación de demo

- Empieza con el login y el título del sistema.
- Entra a Estudiantes y crea un alumno nuevo.
- Abre Reportes para mostrar el gráfico y las métricas.
- Menciona que el backend puede conectarse a una base de datos real fácilmente.
